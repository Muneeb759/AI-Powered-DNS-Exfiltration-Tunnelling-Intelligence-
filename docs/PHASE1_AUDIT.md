## BLOCKING RESOLUTIONS (B1 – B3)

### B1. Stateless vs Stateful Join Analysis
- **a) Raw Headers Verbatim:**
  - **Stateless Raw Header:** `'timestamp,FQDN_count,subdomain_length,upper,lower,numeric,entropy,special,labels,labels_max,labels_average,longest_word,sld,len,subdomain'`
  - **Stateful Raw Header:** `'rr,A_frequency,NS_frequency,CNAME_frequency,SOA_frequency,NULL_frequency,PTR_frequency,HINFO_frequency,MX_frequency,TXT_frequency,AAAA_frequency,SRV_frequency,OPT_frequency,rr_type,rr_count,rr_name_entropy,rr_name_length,distinct_ns,distinct_ip,unique_country,unique_asn,distinct_domains,reverse_dns,a_records,unique_ttl,ttl_mean,ttl_variance'`
  - *Note:* Zero unnamed index columns exist in raw files. `pd.read_csv` absorbed no index columns.
- **b) File Pairings (18 Stateless / 18 Stateful):**
  - All 18 stateless CSV files pair **1:1** with their corresponding 18 stateful CSV files by capture trace key (`heavy_audio`, `light_compressed`, `benign_1`, etc.).
- **c) Row Counts per File:**
  - Stateless files contain **757,211 rows total** (~524 to 132,499 rows per file).
  - Stateful files contain **262,105 rows total** (~143 to 52,438 rows per file).
- **d) Join Existence:**
  - **NO VALID ROW-LEVEL JOIN EXISTS.** Stateless features represent individual DNS packet queries; stateful features represent aggregated window/flow summaries. There is no shared record index or packet ID connecting stateless rows 1:1 to stateful rows. Joining is valid **ONLY AT THE CAPTURE FILE / SESSION LEVEL** (`capture_file` or `session_id`).

### B2. Session Definition Ambiguity Resolution
- **Rule A (`session_id = capture_file_id`)**:
  - **Total Sessions:** 18 sessions
  - **Positive Sessions:** 12 sessions (6 Light-attack sessions, 6 Heavy-attack sessions)
  - **Benign Sessions:** 6 sessions (2 standalone benign, 1 light_benign, 3 heavy_benign)
- **Rule B (`session_id = capture_file_id + "_" + sld`)**:
  - **Total Sessions:** 83,178 sessions
  - **Positive Sessions:** 230 sessions (92 Light-attack, 138 Heavy-attack)
  - **Benign Sessions:** 82,948 sessions

### B3. `sld` Value Distribution & Control 4 Soundness
- `sld` in this dataset was generated by splitting query strings on `.`.
- **Value Category Distribution:**
  - **IP fragments & numbers** (e.g. `192`, `224`, `239`, `172`): Account for **271,715 positive rows** and **175,324 benign rows** (~59% of positive rows and ~38% of benign rows).
  - **Hostnames / NetBIOS / mDNS strings** (e.g. `DESKTOP-3JF04TC`, `FHEPFCELEHFCEPFFFACACACACACACABN`, `local`, `DC`, `isatap`): Broadcast strings during testbed capture.
  - **Real Registrable Domains / TLDs** (e.g. `google`, `microsoft`, `blogspot`, `myshopify`, `com`, `org`): Only a small minority of entries.
- **Conclusion:** `sld` is **NOT a sound registrable domain field**. Relying on `sld` for benign-domain disjointness leaks IP octet fragments and NetBIOS strings that appear in both benign and attack captures. Therefore, **raw `sld` must be EXCLUDED** from feature matrices.

### M4. Stateful vs Stateless Feature Equivalence Check
- **`rr_name_length` vs `FQDN_count`**: Stateful `rr_name_length` (mean: 25.21) measures domain string length in stateful windows; stateless `FQDN_count` (mean: 25.33) measures length per packet.
- **`rr_name_entropy` vs `entropy`**: Stateless `entropy` computes base-2 Shannon entropy per DNS query string (mean: ~2.44); stateful `rr_name_entropy` computes natural log or window-aggregated entropy (mean: ~3.14).

## CLASSIFICATION CORRECTIONS APPLIED (C1 – C7)

- **C1 (`subdomain` flag):** Retained as safe feature `sl_subdomain_flag` (binary flag `{0, 1}`).
- **C2 (`distinct_domains` & `unique_asn` raw exclusion):** Excluded as raw strings to prevent domain/infrastructure identity leakage; re-entered only as numeric counts (`sf_n_distinct_domains`, `sf_n_asns`).
- **C3 (String set/dict parsing to numerics):**
  - `unique_country` $\rightarrow$ `sf_n_countries` (count of unique countries)
  - `unique_asn` $\rightarrow$ `sf_n_asns` (count of unique ASNs)
  - `distinct_domains` $\rightarrow$ `sf_n_distinct_domains` (count of distinct domains)
  - `unique_ttl` $\rightarrow$ `sf_ttl_count` (count of distinct TTL values)
  - `rr_type` $\rightarrow$ One-hot encoded across its 6 discrete values
- **C4 (Derived safe features):**
  - `sl_longest_word_len` = `len(longest_word)` (length only, raw string dropped)
  - `sf_reverse_dns_known` = `(reverse_dns != "unknown")` (boolean flag only, raw string dropped)
- **C5 (Drop 10 constant columns with nunique=1):**
  - Dropped constant columns: `NS_frequency`, `CNAME_frequency`, `SOA_frequency`, `NULL_frequency`, `HINFO_frequency`, `MX_frequency`, `SRV_frequency`, `OPT_frequency`, `a_records`, `distinct_ip`.
- **C6 (Reconcile Day Count):**
  - **Timestamps span 6 calendar days**: `2020-11-20` to `2020-11-25`.
  - Benign data exists on 5 days (`2020-11-20` to `2020-11-24`).
  - Day `2020-11-25` contains 30,401 Heavy attack rows and **0 benign rows**.
- **C7 (`2020-11-25` Ineligible as Held-Out Test Day):**
  - `2020-11-25` is marked **INELIGIBLE** as a held-out test day (0 benign rows makes FPR and PR-AUC undefined on a single-class slice). Split partitioning will draw test days exclusively from `2020-11-20` to `2020-11-24`.
- **Stateful Day Propagation:**
  - Stateful rows receive `collection_day` from their 1:1 paired capture file (`capture_file`), which derives its timestamp and collection day from stateless capture timestamps.
